# 축과 인쇄 숫자 자동 읽기

XRD Studio의 **축 · 숫자 자동 읽기**는 그래프 영역, 축 눈금, 그래프 내부의 인쇄 숫자와 곡선 색상을 찾습니다. 원본 위에서 확인하고 필요한 값만 수정한 뒤 추출하세요.

## 측정 결과

2026-09-09, 로컬 macOS CPU. 기존 `2928d91`과 동일 이미지 비교.

| 검사 | 이전 | 개선 후 |
|---|---:|---:|
| 기존 canonical 이미지 30장: 네 경계 모두 3 px 이내 | 22/30 | 29/30 |
| 추가 합성 이미지 48장: 네 경계 모두 3 px 이내 | 14/48 | 48/48 |
| 추가 48장의 경계 평균 절대 오차 | 84.61 px | 0.15 px |
| 추가 이미지 중 12장: 네 축 끝값 모두 범위의 1% 이내 | 1/12 | 12/12 |
| 추가 48장의 축 위치 계산 중앙값 | 11.97 ms | 70.57 ms |
| 인쇄 피크 숫자 6장, 30개: 정확한 값 + 위치 | 해당 기능 없음 | 29/30 |

인쇄 숫자는 총 29개가 검출됐고 모두 정답과 대응했습니다(정밀도 100%, 재현율 96.7%). **작은 합성 시험 세트의 결과이며 일반 사진에서의 정확도 보장이 아닙니다.** 축 위치 계산은 이전보다 느려졌습니다. 표의 시간은 OCR·프로세스 시작·네트워크를 제외합니다. 전체 자동 읽기에는 OCR 호출 세 번이 추가됩니다.

48장은 고정 seed의 수학적 피크로 생성했습니다. 크기, 여백, 열린 L자 축, 격자, 어두운 배경, 흐림, 노이즈를 바꿉니다. 숫자 시험은 다섯 개의 알려진 소수 라벨을 여섯 가지 배율·배경·흐림 조건으로 렌더링합니다. 개발용 회귀 검사이며 독립적인 실제 논문 사진 평가가 아닙니다.

## 달라진 동작

- 이미지 중심에서 처음 만난 선을 고르던 방식 대신 긴 수평·수직 선분의 교점, 끝점과 영역 크기를 검사합니다. 높은 피크가 Y축으로 선택되던 오류를 줄였습니다.
- 축 숫자는 OCR 텍스트의 픽셀 위치와 값 사이의 선형 관계를 검사합니다. 세 개 이상의 일관된 눈금이 필요하며, 일부 소수점 오독은 합의 검사에서 제외합니다. 읽은 큰 강도를 임의로 100이나 1,000으로 나누던 로직을 제거했습니다.
- 숫자를 읽지 못하면 해당 축값을 비워 둡니다. ‘선 검출 점수’는 선의 지지 정도이며 정확도 확률이 아닙니다.
- 그래프 내부 숫자는 위치 상자와 함께 별도로 반환합니다. 목록에서 원본 위치를 강조하고 값을 수정·삭제한 뒤 CSV로 저장합니다. 숫자를 각도·강도·피크 번호 중 무엇인지 자동 단정하지 않습니다. CSV의 좌표는 **문자 상자 위치**이며 실제 피크 정점 좌표가 아닙니다.
- 검은 곡선 픽셀을 축으로 간주해 버리던 색상 선택을 수정했습니다. 선택 색상은 실제 이미지 픽셀입니다.
- 모드 전환 시 이미지와 보정 상태를 유지하며, 새 이미지로 교체한 뒤 이전 요청이 도착해도 그 결과를 적용하지 않습니다.

## 설치와 재현

```bash
python -m pip install -r requirements.txt
# macOS에서 축 숫자와 인쇄 숫자 OCR 사용
brew install tesseract
# Ubuntu에서는 sudo apt-get install tesseract-ocr

mkdir -p outputs/axis_detection
git show 2928d91:preprocess/auto_detect.py > outputs/axis_detection/baseline_auto_detect.py
python -m eval.benchmark_axes --baseline outputs/axis_detection/baseline_auto_detect.py
python -m eval.benchmark_annotations
python -m pytest -q
```

Tesseract가 없어도 축 위치와 색상 감지는 동작합니다. 실행 중 별도 OCR 모델을 자동 다운로드하지 않습니다. 숫자와 위치는 Tesseract의 [TSV 출력](https://tesseract-ocr.github.io/tessdoc/Command-Line-Usage.html)에서 읽습니다.

## 지원 범위

수평·수직의 직선 축과 선형 눈금이 대상입니다. 기울어진 촬영 사진, 원근 왜곡, 로그 축, 다중 패널, 범례와 겹친 글자, 손글씨, 회전한 피크 라벨, 위첨자와 Miller 지수 `(111)`는 별도 검증이 필요합니다. 내부 숫자 중 범례의 숫자도 후보가 될 수 있으므로 원본과 비교해 삭제하세요. 가려지거나 흐린 소수점은 OCR이 잘못 읽을 수 있습니다. 한 가지 차트만 잘라 올리고 불확실한 값은 직접 수정하세요.

웹 업로드 미리보기는 PNG·JPG·WEBP를 지원합니다. TIFF는 PNG로 변환해 올리세요. 실제 수치 원본이 있다면 이미지 추출보다 **데이터 분석** 탭에서 원본 파일을 직접 여는 것이 좋습니다.
